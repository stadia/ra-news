# 기술 스택

## Backend
- Rails 8
- Ruby 4.0
- Solid Queue/Cache/Cable

## Database
- PostgreSQL + pgvector + textsearch_ko + pg_bigm

## AI
- RubyLLM + Gemini (한국어 요약/임베딩)

## Frontend
- Hotwire (Turbo/Stimulus)
- Tailwind CSS 4.2

## Type System
- RBS inline + Steep

## 필수 PostgreSQL 확장
- pg_bigm: 대규모 텍스트 검색
- textsearch_ko: 한국어 형태소 분석 검색
- pgvector: 벡터 유사도 검색

## 로컬라이제이션
- Default locale: :ko
- Timezone: Asia/Seoul
